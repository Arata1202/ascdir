# Security Policy

## Supported versions

Security updates are provided for the latest release on a best-effort basis. Older releases may be asked to upgrade before receiving a fix. No fixed response or resolution time is guaranteed.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting for this repository. Include reproduction steps, affected versions, and the expected impact when possible.

Do not include real App Store Connect private keys, issuer IDs, key IDs, JWTs, or application metadata in reports or test cases.

Reports are reviewed privately. When a fix is practical, it will be prepared and released before public details are discussed. Coordinated disclosure details will be agreed with the reporter when needed.
